### 🛠️ For developers

- **Open API and SDK**: player resource access, the offline caching framework and the scene/timeline model. [API reference](https://digitalsignage.com/digital_signage/docs/technical/api-reference/) · [SDK docs](https://digitalsignage.com/digital_signage/docs/technical/sdk-documentation/)
- **Embeddable web player**: drop a presentation into your own page, kiosk shell or intranet with an HTML snippet.
- **Data-driven screens**: any XML/JSON feed, RSS/MRSS, calendars; **IoT triggers** from Raspberry Pi GPIO, Arduino, sensors, beacons and REST events. [IoT guide](https://digitalsignage.com/_html/internet_of_things_digital_signage.html) · [Quick start](https://digitalsignage.com/_html/internet_of_things_digital_signage_quick_start.html)
- **Own the stack when you must**: [mediaSERVER](https://digitalsignage.com/_html/mediaserver.html), the whole platform on your own infrastructure for a one-time $895, no monthly fee per screen.
- **White-label for integrators**: the Enterprise plan brands the hosted studio as yours, with multi-account management, proof of play and reseller pricing.
- Reference repositories (not maintained): [signageplayer-core](https://github.com/born2net/signageplayer-core) · [mediaArduino](https://github.com/born2net/mediaArduino)

### 🚀 Screen playing in 15 minutes

1. [Create a free account](https://galaxy.signage.me/signstudio/getstarted/template): email and password, no credit card.
2. Install SignPlayer on the device behind the screen (or open the web player in a browser) and sign in to pair it.
3. Pick a template in SignStudio, publish, done. Screens 2 and 3 are free too; grow from $3 per screen when you need more.

### About StudioLite (this repository)

StudioLite was an open-source (GNU GPL v3) digital signage studio built with Angular, TypeScript and ngrx on top of the DigitalSignage.com cloud and the on-premise mediaSERVER. It is **discontinued and archived**: the code stays available under its license for study or reuse, but there is no roadmap, no releases and no support, and issues opened here will not be worked on. SignStudio, the current editor, uses the same cloud and players, so nothing built with StudioLite stops working.
